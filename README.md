# Tax Loss Harvesting Dashboard

A modern React + Next.js application that simulates **Tax Loss Harvesting** for crypto assets.
It allows users to visualize pre/post harvesting gains and optimize tax savings by selecting assets.

## Live Demo Link

### Setup Instructions

```bash
git clone https://github.com/imkrishn/Tax-Harvesting.git
cd project

npm install
npm run dev
```
